# 保溯

条款可溯源寿险辅助平台的可运行副本。这是本机演示，不是在售保险，不能用来承保或赔付。

## 怎么打开

1. 安装 Python 3.11 或更高版本，安装时勾选 Add python.exe to PATH。
2. 双击“启动保智协同.cmd”。
3. 窗口里出现地址后用浏览器打开，一般是 http://127.0.0.1:8765 。

不填写密钥也能看页面、资料和原文摘录。要接千问时，把 .env.example 复制成 .env，只在自己电脑上填写。.env 已在 .gitignore 里，不要提交。

## 先看

- 当前功能和边界：PROJECT.md
- 零基础介绍：PROJECT_OVERVIEW.md
- 给一起改代码的队友：队友交接说明.md
- 较早的开发交接：交接说明.md
