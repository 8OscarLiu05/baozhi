# 保溯 Baosu

一个智能体中台，连接业务与能力。

保险业务本机演示系统，包含国内中文版和国际英文版。当前版本 **0.17.2 / REQ073-20261018**，本仓库另同步比赛提交版的默认中文启动、版本切换入口和演示资料目录整理。

## 快速运行

需要 Python 3.11 或更新版本，推荐 Python 3.12。网页使用 Edge 或 Chrome。

1. 下载仓库（Code → Download ZIP）并全部解压，或使用 Git 克隆。
2. 安装 Python，Windows 安装时勾选 Add python.exe to PATH。
3. 将 `.env.example` 复制为 `.env`，填写模型接口、模型名称和自己的 API 密钥。
4. Windows 双击 `双击启动.cmd`；其他系统在项目目录执行 `python3 -X utf8 launch.py`。
5. 浏览器默认打开国内版，点击“开始”进入展示页面。

核心演示仅需 Python 标准库。需要上传文字型 PDF 时，另执行 `python -m pip install -r requirements.txt`。

## 国内版、国际版与端口

- 国内版：`http://127.0.0.1:8765/classic/`
- 国际版：`http://127.0.0.1:8765/`
- 页面右下角点击“国内版 / International”切换，两版共用后端和端口。
- 默认端口为 8765；占用时自动选择 8766—8774 中的可用端口。实际地址见启动窗口和自动生成的 `data/server.url`，两个版本地址使用同一个实际端口。
- 服务仅监听本机地址；以上网址应在启动服务的电脑上打开。

## 模型配置

`.env` 配置示例见 [.env.example](.env.example)。接口地址填写完整的 OpenAI 兼容 Chat Completions HTTPS 地址；接口区域必须与密钥对应。模型需要联网且账户额度有效。不配置密钥仍可查看页面和结构化条款，模型咨询会提示不可用。

普通咨询可输入“等待期和犹豫期有什么区别？”。国内版专业咨询可输入“中宏健康双星等待期多少天？”。英文普通咨询可输入“What is the difference between a waiting period and a cooling-off period?”。

如模型连接失败，请检查网络、配置和额度；本项目曾遇到美国地区全局代理导致接口连接失败。

## 当前回答机制

- 普通咨询：调用一次模型，不附带公司资料。
- 国内专业咨询：命中授权字段后调用一次模型解释；数字或话术检查不通过时保留字段答案。
- 国际专业咨询：直接返回英文字段答案，不调用模型。
- 电话中心和岗位助手：一般方法题调用模型，具体产品题查询授权字段及摘录，字段命中时使用字段模板终答。
- 中台助手：整理本机运行快照后调用模型解释。

产品不明、字段缺失、收益类和风险问题等按各分支澄清或回退，不能把所有任务写成固定的一条模型流水线。

## 仓库内容

- 根目录 Python 文件：服务、业务路由、模型调用、授权、字段查询及治理逻辑。
- `static/`：国际版网页；`static/classic/`：国内版网页。
- `演示资料/`：公开条款结构化样例和利益演示数据。
- `docs/ARCHITECTURE.md`：与当前实现对应的架构说明。
- `tests/`：专业咨询分支的自动化回归测试。

首次运行自动创建 `data/baozhi.sqlite3`，含程序生成的虚构演示数据，不携带开发历史数据库。此源码仓库不含比赛包中的私人密钥或便携 Python；比赛 ZIP 与 GitHub 源码包的安装方式不同。

## 验证

```sh
python -m unittest discover -s tests -v
```

测试使用临时数据库和模拟模型响应，不消耗模型额度；不代表真实接口连通性或保险专业准确率。

## 演示边界

三个业务入口是模拟接入，未连接真实展业 APP、微信、电话或保险机构生产系统。客户、公司和保单为虚构数据；公开条款保留原公司、产品及出处，不表示虚构保单获得真实承保。只有千问已接入，其他模型仅预留。调用反馈不自动写入条款知识库。

请勿将 `.env`、密钥、运行数据库或真实个人资料上传 GitHub。公开条款资料的来源说明保留在样例中；仓库未另行授予第三方资料的再许可。
