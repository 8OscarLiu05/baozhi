# 已知限制

- 真实模型当前缺运行配置，线上接口、有效响应、费用、候选数量和证据质量均未实测。脱机提取为合成测试。
- PDF 文本层是当前主流程。低文本或乱码页隔离待核验，未实现 OCR、版面回读或自动跨页合并。表格类附件可选 pdfplumber 网格识别与行列坐标，复杂表头及事实到表格单元格的绑定仍需人工核验。本轮真实样本未验证表格附件链路。
- 自动核验只是引用/格式和风险拦截。中文数词、条件的语义等价、例外完整性、跨条款推理均需专业判断。当前发布每版每字段一条记录，多个互斥分支宜在同一字段保留完整条件说明，通用规则表达式与金额计算尚未接入。
- 权限为本机分岗令牌，审计识别本机角色；尚无企业认证、人员唯一账户或审计防篡改。生产不应沿用演示身份。合法主附险的跨版本证据关系未开放。
- 解析及抽取是同步请求。没有持久后台队列、崩溃任务回收、批量并发处理或资产规模压测。当前原件保存在 SQLite BLOB，保留大小上限。
- 国内版提供最小工作台与展业入口，其他业务入口及英文版沿用原路径。前端通过脚本检查和 HTTP 等效验证，浏览器实操、视觉排版和辅助技术尚待验证。仅为显式选择产品版次的字段读取，未接入通用自然语言版本推断。
- 下一步先配置真实模型并运行国寿样本，取得并核验附件后准备专业审核。审批后以同版已发布证据验证展业，再扩展到其他产品与入口。
