# 风险与验收

| 风险 | 控制 | 验收方式 |
|---|---|---|
| 旧发布或候选误入正式答案 | 新快照独立读入口，历史演示身份保留 | 用草稿、待审、驳回、撤回、legacy published 注入测试。正式知识暴露计数为 0 |
| 版本、主附险和渠道混淆 | 同版外键、服务器授权、版本歧义澄清 | 两版本同字段异值、已停售合同、缺日期、主附险不符、两产品对比与跨岗位访问 |
| 材料效力错用 | 按事实类型检查证据适用性 | 说明书演示数字、非保证分红、现金价值表版次和冲突场景均不得形成错误保证结论 |
| 数值、条件或否定关系错误 | 模板和确定性计算，条件/例外随事实发布 | 数值相同但单位不同、错领年龄、身故前后、跨页条款、缺附件、未知分支 |
| OCR、解析与证据错配 | 页级标记、锚点及引文复核 | 文字页、混合扫描、坏件、合并表头、目录重复、跨页脚注。事实定位到原件实际页 |
| 任务重试和并发发布 | 幂等键、租约、原子发布、版本检查 | 重复上传、进程中断、重复审批、并发发布、陈旧审核、回滚后的历史重放 |
| 模型注入、语义篡改和超时 | 只读工具、服务器渲染、结构校验 | 嵌入提示、错误数字、相同数字换责任、遗漏例外、伪造引用、模型超时。高风险未授权断言为 0 |
| 历史数据、隐私和授权 | 新资料私有存储、Git 提交拦截、脱敏及访问审计 | 核对受权下载、非发布者 403、密钥和 PDF 拦截；备份和回滚验证。现有演示角色不作为生产认证 |
| 双版本与旧流程退化 | 适配 API、功能开关、影子比对 | Python 回归、两版浏览器烟测、同场景证据一致、中文/英文显示与历史查阅 |

## 专业质量指标

首份双人独立审阅高风险事实，争议由指定专业人员裁定。独立应提取清单从原文建立，先冻结再看候选。后续按风险分层，保留样本数、抽样种子和覆盖类型。按文件、字段和高风险层分别报告，不能把局部通过率当整体指标。

| 指标 | 分子 / 分母或取法 |
|---|---|
| 字段准确率 | 人工核验正确的候选 / 人工核验过的候选 |
| 字段召回率 | 正确匹配的应提取事实 / 人工原文基准中的应提取事实 |
| 证据可追溯率 | 人工确认定位正确且足以支持事实的候选 / 需要判断的全部候选。若只审核样本，报告样本估计与覆盖率 |
| 条件、例外完整率 | 各自完整的事实 / 人工判定存在对应条件或例外的事实 |
| 高风险错误率 | 人工发现实质错误的高风险候选 / 已核验高风险候选 |
| OCR 错误率 | 对标人工转录的字符编辑距离 / 基准字符数；非扫描样本记 NA |
| 自动拦截与工时 | 被拦截候选 / 输入候选，并报告拦截精度与漏报；记录每份合同加工耗时与人工审核分钟 |

建议首批准入门槛为已发布事实 100% 有有效证据和审批、高风险阻塞未解决数为 0，测试中候选泄漏、跨版错误和未授权合同断言均为 0。提取准确率与召回率先用专业标注建立基线，再确认可接受阈值。没有人工分母时记未评估，不能用程序回归或模型置信度填充。历史验证批次可作为答复回归资产，不能代替新合同的抽取质量评价。
