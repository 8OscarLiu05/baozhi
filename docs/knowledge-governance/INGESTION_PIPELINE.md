# 知识加工与审核流程

## 输入到发布

1. 批量登记。逐项选择公司、产品及合同版次、材料类别、官方来源和预期用途。核验官方页面与最终下载 URL、附件身份、版本、页数和备案号。用原件 SHA-256 去重，原子落盘并记录来源观察，内容或版本异常隔离。
2. 解析。沿用 pypdf 处理文字页，记录页级字符数、文本质量和物理页码。低文本密度、乱码、嵌图表格触发页级 OCR 或人工确认；只有样本确有需求后才选择 OCR 组件。限制解压体积、单页像素、时长；截断、加密和失败保留原因。
3. 清洗。保留原始页文本、清洗映射和解析版本；按编号与层级拆分，识别目录、重复页眉、跨页段落。保留脚注、标题、列单位及原文坐标。复杂表记录行列/合并单元格和表头继承。公式或表无法复原时不让模型填补。
4. 候选抽取。按材料类型和产品版本划分批次。模型只读指定证据片段并输出 JSON Schema；带页号、条款、原文区间、字段类型、单位、条件、例外和引用。文档内指令视为数据。记录模型配置标识、提示词版本、输入指纹、请求和响应标识、耗时及结果。失败支持重试，同配置同资产可复现任务身份，模型结果本身可能有波动。
5. 自动校验。验证 Schema、引用定位和引文一致性、数值与单位、证据适用性、版本归属、重复/冲突、缺失条件及跨条款依赖。语义完整性用字段要求、依赖和人工裁定补足。高风险无证据、版本冲突和条件缺失阻塞发布。
6. 审核。首份全部候选逐条审，另从原文反向建立应提取事实集。后续责任、领取、金额、身故、免责、红利及账户关键字段全部审，低风险元数据按材料、字段及解析质量固定种子抽样；发现系统性错误扩大同层复核。审批绑定修订和证据哈希，修改产生新修订。
7. 发布。审核通过且未解决阻塞数为零，发布人预览差异后原子生成快照。知识抽检与答复抽检分流，业务抽检能发起待办，不能自动改事实。

任务采用 queued → running → succeeded / failed / quarantined。失败含重试分类、租约过期回收和次数上限。候选采用 proposed → needs_review → approved / rejected；修订替换后保留旧审核记录，发布只引用已批准修订。对 OCR 缺页或关键附件缺失可允许核准独立事实，但禁止发布依赖缺失内容的字段，缺口须显示。

错误编码 E01 解析、E02 提取、E03 条件、E04 例外、E05 版本、E06 证据、E07 无依据、E08 分类、E09 遗漏、E10 重复。每条记录任务、修订、字段、候选、原文、原因、处置及审核人。按根因修正解析/校验/提示，再用冻结集与独立留出样本比对，防止用审核答案污染验收集。

## 养老年金验证样本

协会页面初核显示中国人寿和国民养老两项为停售，分别列出 TERMS 附件线索；国民养老现金价值链接为占位。太保交接中的历史页面当前抓取不可用。三个品种的 PDF 字节、备案号、完整性和附件适用性仍需在试点阶段验收。本阶段资料核验仅到目录页面，未形成可用原件或知识数据。

- 普通型样本。验证起领日、年/月领取、保证领取与身故关联。[协会明细](https://www.iachina.cn/IC/tkk/01/006a722a-8a0f-4171-8fd5-35a013757798.html)
- 分红型样本。核对正式条款与说明书的身份，验证保证与非保证的分层。[公司历史版本线索](https://cpic.com.cn/c/2026-06-30/1884224.shtml)
- 专属商业养老样本。验证账户、费率、结算与转换表，缺附件时阻塞相关字段。[协会明细](https://www.iachina.cn/IC/tkk/01/e6ca10a9-3c32-4bac-9d09-38e81f9b6107.html)
