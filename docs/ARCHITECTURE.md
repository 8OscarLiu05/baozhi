# 当前系统架构

对应版本：0.17.2 / REQ073-20261018；包含比赛交付时补充的语言入口与资料目录整理。

## 四层结构

1. 系统集成层：展业、客户自助、电话中心三个演示入口，通过 `/api/channel` 提交问题；电话中心分外呼、坐席和质检。
2. 应用能力层：业务岗位智能体和中台五个助手（知识治理、运行观测、抽检研判、授权编排、口径中枢）。
3. 平台能力层：职责和资料授权、字段查询、证据检索、请求分流、数字检查、话术规则、调用留痕与追加复核。
4. 基础能力层：千问兼容接口、本地 Python 服务及 SQLite 存储。

应用能力层与平台能力层共同构成智能体中台。四层是逻辑划分，实际部署为一个本地 Python HTTP 服务，不是四个独立微服务。

## 代码职责

- `app.py`：HTTP 路由、数据库初始化、会话及职责检查、问答分支和记录落库。
- `portal_hub.py`：预置智能体、提示词、统一模型请求和返回校验。
- `company_library.py`：虚构机构、员工、客户、保单、职责与智能体授权。
- `life_catalog.py`、`clause_query.py`：公开条款 JSON 导入、字段及条件查询、数字文本核对；未使用向量数据库。
- `consultation.py`：普通/专业咨询结果组织、自编需求情景查询。
- `compliance_rules.py`：承诺赔付或承保、收益保证、与存款或理财比较、夸大或贬低等规则。
- `platform_ops.py`：中台助手使用的知识、调用及授权快照。
- `intl.py`：英文关键词路由、英文模板、错误信息与语言记录筛选。
- `illustrations.py`：独立利益演示表，不进入对话检索。
- `external_material.py`：可选外部材料导入；`insurance_content.py`、`product_design.py`、`simulation.py` 保留其他演示能力。
- `launch.py`：端口选择、服务启动与默认国内版入口。

## 数据与调用

`products`、`product_duties`、`product_exclusions` 保存结构化产品事实；`documents`、`chunks`、`clauses` 保存资料与证据。虚构客户和保单仅提供业务上下文。

普通咨询直接调用一次模型。国内专业咨询只在授权字段命中且满足条件时调用一次模型解释；国际专业咨询使用英文字段模板。需求情景查询不调用模型。电话中心和岗位根据问题类型选择方法回答、字段终答、摘录或澄清。中台助手使用本机快照。

调用记录分别保存模型状态、调用次数、是否采用正文、来源及检查结果，不能把接口成功等同于正文采用。人工复核追加记录，不覆盖原回答，也不自动更新知识。

## 双版本

`/classic/` 提供国内中文页面，`/` 提供国际英文页面；国际版请求使用 `X-Baosu-Lang: en`。两版共用服务、数据库和模型配置，语言记录由程序筛选，不属于两个独立部署或机构级隔离。

双击启动默认进入 `/classic/`，页面右下角提供版本入口。默认端口8765，冲突时向后尝试至8774。
