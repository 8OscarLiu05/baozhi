## 新知识模式的安全初始化
使用独立虚构数据沙箱，不复制正式源库，也不把本次未审核真实资料发布。
从新克隆仓库根目录执行以下PowerShell：
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-knowledge-verified.txt
New-Item -ItemType Directory -Force -Path work/knowledge-private | Out-Null
if (Test-Path -LiteralPath work/knowledge-private/sandbox.sqlite3) { throw '沙箱已存在，请先核验，不覆盖' }
.\.venv\Scripts\python.exe -X utf8 -c "from pathlib import Path; from app import Store; from knowledge_store import KnowledgeStore; p=Path('work/knowledge-private/sandbox.sqlite3'); Store(p); KnowledgeStore(p,migrate=True); print('已建立独立虚构数据沙箱')"
```
此库初始没有本轮真实PDF与知识候选。资料包不附运行数据库；必须单独登记原件。

安全生成三种只限本机的不同岗位凭据：
```powershell
$env:BAOZHI_KG_BUILDER_TOKEN = python -c "import secrets; print(secrets.token_urlsafe(32))"
$env:BAOZHI_KG_REVIEWER_TOKEN = python -c "import secrets; print(secrets.token_urlsafe(32))"
$env:BAOZHI_KG_PUBLISHER_TOKEN = python -c "import secrets; print(secrets.token_urlsafe(32))"
.\.venv\Scripts\python.exe -B -X utf8 app.py --port 8765 --knowledge-sandbox work/knowledge-private/sandbox.sqlite3
```
界面：http://127.0.0.1:8765/classic/knowledge.html 。
操作者只在本机取得对应令牌输入，不把令牌复制到PPT、聊天或Git。该机制为本机分岗，非企业生产身份系统。
正式业务读取另需通过BAOZHI_KG_SALES_VERSIONS开放已发布的版次ID，不能先编造ID。
模型可继续跳过；真实调用需用户自己在本机配置BAOZHI_MODEL_URL、BAOZHI_MODEL、BAOZHI_API_KEY。

## 登记本地完整包里的真实条款
在沙箱已初始化后，可使用tools/run_knowledge_pilot.py登记核验过的正式PDF；命令参数分别是沙箱数据库、条款PDF和输出目录，不加--extract就不触发模型。工具校验固定SHA-256并拒绝受保护默认库。
配套附件工具tools/register_pilot_attachments.py需要private目录内cash.download、rates.download、brochure.download这三个文件名，均对应本包同版官方PDF。由队友Codex核对哈希后复制准备，再执行。它不会批准合同事实。
tools/prepare_annuity_review_packet.py需要已登记条款与附件的沙箱，可重建表格与审核导航。
tools/serve_knowledge_browser_test.py是临时真实/合成双服务验证工具，内有固定测试角色凭据，只能用于本机临时测试；不得作为生产服务启动器。空真实沙箱也可启动，但没有已登记真实材料可看。
