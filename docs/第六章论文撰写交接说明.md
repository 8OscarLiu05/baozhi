## 3. 两名评审者怎么填写

1. 复制一份工作簿作为备份，不改题目、标准或系统答案。
2. 评审者A只填写“评审A”，评审者B只填写“评审B”；两人评分前不要查看对方页签。
3. 四项指标分别选择“合格、不合格、不适用、标准争议”。不合格或争议必须写理由。
4. 负责人在“分歧裁定”页查看自动提示，只填写四个“最终”列和裁定说明。
5. 完成后锁定工作簿，把“概览”中的表4复制到论文，同时报告分子、分母。
6. 计算各指标95% Wilson置信区间，以及A/B原始一致率和Cohen's κ。若某类极不平衡，同时报告类别分布。

请不要把工作簿里当前的“待评”改成默认合格，也不要在发现失败后删除题目。
